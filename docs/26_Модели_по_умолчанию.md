# GigaChat и GigaAM при обычном запуске

Дата: 28.10.2026. Исходная объединённая версия — `c9bd172777d062f74994ee3074b819f0e9821878`. Цель — запускать именно эту версию с GigaChat-2-Max для разбора текста и локальной GigaAM-v3 E2E CTC INT8 для голоса по умолчанию.

## Что изменено

- Стандартный режим `ODIN_MODE=models` выбирает GigaChat-2-Max и ожидает локальную GigaAM. Если нет ключа или папки модели, приложение не начинает работу молча в режиме правил. Во время загрузки или при недоступности GigaAM проверка `/health` возвращает 503. Сам `/health` не проверяет облачную модель сетевым вызовом.
- При временной ошибке уже подключённой языковой модели сохранён резервный разбор правилами; в ответ добавляется заметное сообщение о недоступности модели. Режим только правил для прямого запуска Python выбирается явно через `ODIN_MODE=rules`.
- Docker-образ содержит библиотеку и CPU-зависимости GigaAM. Веса остаются вне образа и подключаются в контейнер только для чтения. Личный файл с настройками GigaChat тоже подключается только для чтения; значение ключа не передаётся через переменные контейнера и не записывается в Git или архив исходников.
- В текущей локальной рабочей версии создан исключённый из Git `.env` с путями к уже существующему личному файлу настроек и проверенной копии весов модели. Сам ключ не копировался. Проверены SHA-256 весов и словаря; скопированы только файлы модели, без профилей и истории.
- В папке результатов на этом компьютере подготовлен запускатель `Запустить_Один_запрос.cmd`. Он использует Docker Desktop и местные пути; проверенную сборку может повторно использовать без пересборки, если исходники и образ не изменились. Этот запускатель привязан к рабочей папке текущего чата. Переносимый ZIP содержит исходники и инструкцию, но не личный ключ и не веса.

В конфигурации другого компьютера нужно указать разрешённый ключ GigaChat в локальном `.env` либо путь `ODIN_SECRET_ENV_FILE`, а также разместить веса рядом с проектом или указать `ODIN_VOICE_MODEL_DIR`. Подробнее — README. Личный ключ владельца не является ключом для жюри.

## Границы

GigaChat — облачный сервис: текущая реплика и необходимые параметры поездки передаются поставщику. GigaAM работает на сервере приложения; в проверенной локальной конфигурации это компьютер владельца. Четыре реплики и одна аудиозапись не подтверждают качество на произвольной речи; настоящий микрофон в этом прогоне не проверялся. Реальные цены, бронирование и оплата не подключены.
