## Что объединено

- Новый глобус, источник и типы точек, 3D-ориентиры, события, мобильный интерфейс, настройки валюты и звука, избранное, сравнение и встраиваемый виджет работают с обновлённым диалогом и его 75 направлениями. Сохранён раздел об источниках данных и демонстрационных условиях.
- Сервер сохраняет блокировку конкурентных изменений сессии, заголовок `no-store`, фильтр лишних данных, контекстные подсказки и обработку уточняющих вопросов. Для сводки возвращается подтверждённое направление и явно распознанная длительность. Запрос информации о завтраке или парковке сам по себе не становится требованием.
- Визуальные подсказки дат и состава сохранены. При неоднозначности новая поездка/изменение текущей интерфейс показывает оба варианта, предложенные сервером; пустой список серверных подсказок не заменяется устаревшими действиями по одному этапу.
- Для карточек часть повторяющихся подробностей скрыта из компактного ответа, но полный текст сервера доступен по ссылке «Показать полный ответ» как на сайте, так и в виджете. Ответы на дополнительные вопросы показываются целиком.
- При пустом поле кнопка запускает голосовой ввод, повторное нажатие останавливает запись. Текст остаётся редактируемым и не отправляется без отдельного действия. Возможны браузерное распознавание или отдельно настроенная GigaAM на сервере приложения. Закрытие виджета прекращает запись; пояснение об обработке доступно рядом с полем. Установка модели и её весов по-прежнему отдельная.
- Удалены временная копия картографической базы дизайн-ветки и её адаптеры. Сайт и агент используют один индекс `domains/trips/data/map_catalog.sqlite3`, собираемый из включённых исходных снимков командой `python -m tools.build_map_catalog`; Docker выполняет это при сборке. В Git сам построенный индекс не включается.

При сравнении старого снимка дизайн-ветки и построенной базы обе прошли `PRAGMA quick_check`, имеют одинаковые источники и по 283 561 записи: 65 924 объекта размещения, 48 101 аэропорт, 161 662 географические записи, 7 866 пляжей и 8 кемпингов. Сравнение полных строк обнаружило только 58 исправлений географического кода XK: новая сборка указывает название «Косово» и код XK вместо старого названия `XK` без кода. Дайджесты исходных данных различались (`bb2a391b81a2832ba026e55eb31e224887bdb570d0fde58d64f854caaf67cd32` и `859b7e973c829f676d2de29a40a40ff77c0e04f02b79b2712c5f075be2e4fd6c`); равенство дайджестов не заявляется. Повторить сравнение можно через `python -m eval.compare_map_databases_20261028 --design-db <распакованный-снимок-из-46da450> --combined-db domains/trips/data/map_catalog.sqlite3`. Исходный сжатый снимок остаётся в истории дизайн-ветки.

## Ограничения

В проверке объединённой версии с действующей моделью использован только один короткий синтетический диалог; она не устанавливает качество на произвольных формулировках. Настоящий микрофон не проверялся. Браузерные сценарии записи используют имитацию микрофона, а отдельный HTTP-тест подключает реальную локальную GigaAM к одной открытой записи. Браузерное распознавание может отправлять аудио своему поставщику; серверная модель обрабатывает его на сервере приложения, который может быть удалённым. Эвристический фильтр не гарантирует обнаружение всех личных данных.

Локальный предпросмотр был запущен с существующим личным доступом владельца и уже установленными весами GigaAM вне Git. Это не разрешённый ключ для жюри. В архиве и обычном Docker-образе нет ни личного ключа, ни весов GigaAM: их настройка для другого запуска выполняется отдельно. GigaChat-2-Max использовался для извлечения параметров; свободная генерация текста ответа моделью в этом тесте не включалась.

Цены, расписания, рейтинг и оформление демонстрационные; настоящая доступность, покупка и бронирование не подключены. Курс фиксирован по снимку на 28.10.2026, события добавлены вручную. Холодный запуск на компьютере жюри, независимая проверка качества, финальное видео и метка сдачи в рамках этого объединения не выполнялись.
