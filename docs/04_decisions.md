Известные ограничения прототипа:
- Через merge нельзя сбросить параметр («бюджет не важен»): `null` в update означает «не изменилось».
- У домена отелей нет разбора фраз по правилам: без LLM агент не понимает запрос.
- Каталог отелей вымышленный; реальные данные появятся 23 октября.
