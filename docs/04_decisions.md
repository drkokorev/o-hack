Известные ограничения MVP:
- Через merge нельзя сбросить параметр («бюджет не важен»): `null` в update означает «не изменилось».
- Правила не понимают числа словами («в десять тридцать») и имя пациента внутри длинной фразы без «меня зовут». Это закрывает LLM.
- Нет перевода на оператора при срочных жалобах.
