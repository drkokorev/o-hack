## Зафиксированные неудачи

1. Первый запуск сервера без полного Python-окружения не нашёл `dotenv`; использовано существующее совместимое окружение, повтор прошёл.
2. Первый аудиодубль потерял начальное «Из Москвы», но распознал состав путешественников. Город явно введён последующей репликой; полный исходный аудиозапрос не выдаётся за точно распознанный.
3. Первый сценарий браузерной записи встретил два одноимённых элемента «Перейти к оплате». Сценарий записи уточнён, повтор прошёл. Код приложения не менялся.
4. Репетиционная фраза «Что посмотреть в Дубае?» превратила направление в «Дубае» и попросила уточнение. В итоговом дубле используется проверенное «Что там посмотреть?» с сохранённым Дубаем. Это известная граница версии, а не обещание понимания всех формулировок.
5. Первая сцена виджета восстанавливала предыдущий диалог с маскированным сообщением. Для отдельной демонстрации выполнен новый обычный запрос в чистой браузерной сессии.
