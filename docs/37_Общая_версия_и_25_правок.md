## Данные и интеграция

Начальная проверка старого checkout выявила только 7 отправных городов и отсутствие путеводителей. Пока выполнялись правки, в artemiy появилась объединённая модельная версия. Она включена: итоговый каталог содержит 290 отправных городов и 75 направлений. Совместно с данными перенесены их схемы, обработка ближайшего аэропорта, семантический поиск и проверки. Повторяющиеся коды аэропортов у разных городов не считаются дублями города: один аэропорт может обслуживать несколько населённых пунктов. Сравнение исходных снимков — [datasets-before-merge.json](evidence/refinement_20261029/datasets-before-merge.json), общей версии — [datasets.json](evidence/refinement_20261029/datasets.json).

Все 32 GLB и локальный Draco-декодер подключены к текущему общему WebGL-слою. Не перенесён старый интерфейс с отдельным canvas для каждой миниатюры. Выбор и группировка мест, маршруты, события, темы и восстановление графики сохранены. При приближении центральная достопримечательность получает приоритет: модель не теряется за более известным соседним объектом. Все 32 модели декодированы и все 32 карточки открыты в работающем сайте. Материалы ветки моделей в `docs/landmarks-3d-20261029/` описывают её первоначальные проверки; актуальные проверки интеграции лежат в `evidence/refinement_20261029/`.

Прогноз запрашивается только для поддерживаемого горизонта. Open-Meteo документирует до 16 суток: [официальная документация](https://open-meteo.com/en/docs). При частичном покрытии показаны даты прогноза. Отказ сети не подменяется историческими значениями.

## Автоматический город по IP

Подсказка сохранена, видимая пометка убрана. Включён компактный производный индекс [DB-IP City Lite](https://db-ip.com/db/download/ip-to-city-lite), октябрь 2026, CC BY 4.0. Полный файл используется только при подготовке; посетительские IP не отправляются наружу. В поставку входит `origin-ip-index.json.gz`, собственная MMDB остаётся необязательной. Исходный снимок, команды, размеры и покрытие записаны в доказательствах. Скрипт `tools/build_origin_ip_index.py` воспроизводит индекс из официального файла. Это приблизительная подсказка: VPN, неподдерживаемые адреса и localhost могут не дать город. Явное «из Самары» заменяет предположение. Чужой одноимённый Moscow не превращается в Москву.

## Проверки и ограничения

Код общей версии: `0d60bd10dabfcd93f14192eadc68c5881b173c3b`. Пройден полный набор из **796 тестов**; после добавления встроенного IP-индекса отдельно прошли **16** проверок города и приватности. В браузере: **41** проверка основного интерфейса, **7** восстановления глобуса, **32** миниатюры и **6** финальных проверок города/календаря. Живая модель — **4** шага, GigaAM сообщает `ready`. Счётчики пересекаются и не суммируются.

Встроенная IP-база занимает **427 916 байт**, содержит **25 003 IPv4** и **7 427 IPv6** диапазонов для **244 из 290** поддерживаемых городов; отсутствие записи не заменяется выдуманным городом. [Происхождение и контрольные суммы](evidence/refinement_20261029/origin-ip.json).

Полный реестр с фактическими результатами, исходником и командами — [checks.json](evidence/refinement_20261029/checks.json). Скрипты: `tools/verify_refinements.js`, `tools/verify_globe_recovery.js`, `tools/verify_integrated_landmarks.js`, `tools/audit_design_datasets.py`; запуск через Playwright CLI по README навыка или существующий Playwright. Сервер тестовых сценариев — `http://127.0.0.1:18191`, режим rules; живая модель проверяется отдельно `python -m tools.verify_design_models --base ... --output ...`.

Голосовые проверки используют синтетические аудиосэмплы и заглушку транскрипции; реальный микрофон не записывался. Модель GigaAM проверяется на готовность, это не проверка качества распознавания. Не проводились замеры FPS на физических слабых устройствах, сборка установщика и реальные платежи. Цены, доступность, транспорт и оформление остаются демонстрационными. Наличие всех фотографий событий не заявлено.

Зафиксированы и неудачные проверки: первый сбой WebGL дал исключение и исчезновение поверхности; первая попытка ремонта восстановила ресурсы, но не удалённый слой. После исправления обе планеты прошли принудительную потерю контекста. Первые браузерные проверки имели неверный относительный URL и зависели от регистра названия месяца; сценарии исправлены. При объединении календарей обнаружено попадание MouseEvent в флаг выбора одной даты; исправлено, диапазон проверен заново. В объединённом окружении 2 теста семантического поиска упали из-за отсутствовавших ONNX/tokenizers; зависимости добавлены в отдельную папку стенда, полный набор затем прошёл. Первая загрузка IP-базы захватила апостроф в URL и получила 404; URL исправлен. Первый индекс не учитывал английские псевдонимы исходных семи городов; проверка Москвы выявила ошибку, индекс пересобран.

Финальная проверка одиночной даты сначала проверяла удаление диалога до завершения события `close`. В сценарий добавлено ожидание; все шесть финальных проверок прошли.
