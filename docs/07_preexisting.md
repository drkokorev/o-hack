# 07. Компоненты, созданные до начала хакатона

Всё перечисленное создано **с 4 по 22 октября 2026 года**, до старта «О! Хакатона» 23 октября. Даты зафиксированы коммитами в репозитории github.com/drkokorev/o-hack: `7bbf120` от 11 октября и коммит от 22 октября с разбором правилами, загрузчиком каталога, веб-демо и оценкой.

| Компонент | Файлы | Что это |
| :--- | :--- | :--- |
| Ядро диалогового агента | `core/` | Цикл обработки реплики, OpenAI-совместимый клиент LLM, структурированное извлечение с ремонтом JSON, защита от инъекций, русское форматирование |
| Прототип домена отелей | `domains/hotels/` | Поиск и ранжирование на **вымышленном** каталоге, лестница ослабления фильтров |
| Интерфейс и тесты | `apps/cli.py`, `tests/` | Консольный чат, автотесты |
| Разбор запроса правилами (22 окт) | `domains/hotels/rules.py` | Город, даты, гости, бюджет, звёзды, удобства, расположение, сброс параметров без LLM |
| Загрузчик каталога (22 окт) | `domains/hotels/loader.py`, `tools/inspect_data.py` | Чтение табличных данных общего вида с автоопределением колонок; обзор данных. Под конкретные данные Островка не настроен |
| Веб-демо (22 окт) | `apps/web.py`, `apps/static/` | Чат, карточки отелей, панель понятых параметров |
| Оценка (22 окт) | `eval/`, `tools/llm_check.py` | Наборы диалогов на вымышленном каталоге, скрипт метрик, проверка доступа к LLM |
| Документация | `docs/`, `README.md`, `THIRD_PARTY.md` | Анализ условий, архитектура, план |

## Что создаётся на хакатоне (конкурсная работа)

- Адаптер и логика под **реальные данные и задачу Островка**, выданные 23 октября.
- Работа с отзывами, агентный слой, интерфейс.
- Метрики, презентация, демо.
