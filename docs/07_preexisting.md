# 07. Компоненты, созданные до начала хакатона

Всё перечисленное создано **с 4 по 11 октября 2026 года**, до старта «О! Хакатона» 23 октября. Дата зафиксирована коммитом `7bbf120` от 11 октября 2026 в репозитории github.com/drkokorev/o-hack.

| Компонент | Файлы | Что это |
| :--- | :--- | :--- |
| Ядро диалогового агента | `core/` | Цикл обработки реплики, OpenAI-совместимый клиент LLM, структурированное извлечение с ремонтом JSON, защита от инъекций, русское форматирование |
| Прототип домена отелей | `domains/hotels/` | Поиск и ранжирование на **вымышленном** каталоге, лестница ослабления фильтров |
| Интерфейс и тесты | `apps/cli.py`, `tests/` | Консольный чат, автотесты |
| Документация | `docs/`, `README.md`, `THIRD_PARTY.md` | Анализ условий, архитектура, план |
