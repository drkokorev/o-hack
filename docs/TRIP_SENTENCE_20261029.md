# Поездка одной фразой — 29 октября 2026

Задача: убрать повтор «Ваша поездка / Все условия» и сделать значения прямо в краткой фразе редактируемыми. Владелец выбрал фразу вместо набора отдельных полей, затем уточнил, что должны учитываться погодные пожелания и ограниченное место на экране.

Исходная версия: `4cf50bb9ad44cb18bda48820761c581c5a50b3c1`, ветка подготовки `codex/trip-sentence-20261029`. Основа — сохранённая интегрированная версия интерфейса из `codex/design-review-20261028`. В соседней рабочей копии были незавершённые изменения, поэтому работа выполнена отдельно. Это изменение не объединяет ветки `main`, `artemiy` или другие параллельные ветки.

## Что изменилось

- Основные значения — отправление, направление, даты, ночи, состав и общий бюджет — представлены одной фразой. Нажатие открывает конкретное поле; даты открывают календарь. Год остаётся видимым, при переходе между годами показываются оба года.
- Дубли основных значений удаляются только по точному совпадению. Возраст детей, условия доступности, транспорт, предположения и другие самостоятельные ограничения сохраняются.
- Дополнительно на экране находятся не более двух пожеланий. Остальные открываются через «Ещё N», без повтора основных значений. Границы температуры одного вида сгруппированы: «Воздух 25–30 °C».
- Порядок дополнительных акцентов задан явно: указанные пользователем температурные ограничения, затем некоторые конкретные ограничения поездки, питание, остальные пожелания, предположения. Это правило отображения, а не обученная оценка важности. Пользовательская настройка закрепления акцентов не реализована.
- Общая кнопка «Изменить» заменена добавлением пожелания. Редактор конкретного поля содержит его текущее значение, «Применить» и «Отмена». Пустой обязательный ввод отклоняется браузером; неизменённый ввод не создаёт запрос. При сетевой ошибке значение и ошибка остаются в редакторе.
- Изменение направления явно формулируется как правка текущей поездки; раньше «Хочу в …» могло вызывать уточнение о новой поездке. Правка параметра не перезаписывает последнюю реплику, если в поле ввода был включён режим её редактирования.
- Исправлен обнаруженный при проверке разбор «температура воздуха от 25 до 30 градусов»: сохраняются обе границы. Для диапазона по-прежнему нужны единицы измерения; даты и вопросы о прогнозе не превращаются в пожелания.

## Дизайн

Используются существующие шрифт, палитра и темы. Подчёркивание показывает интерактивность, элементы доступны клавиатурой, области нажатия имеют высоту не менее 44 px. Дополнительные пожелания занимают вторую визуальную ступень. Нет постоянной строки-инструкции и повторного заголовка внутри карточки.

Для проверенного примера: основная фраза — 147,8 px; с погодой и «Ещё 6» — около 191,8 px. Однократная строка смены направления временно увеличивает высоту до 223,6 px. Проверены ширины 1440, 390 и 320 px; горизонтального переполнения не было. Это измерения конкретных сценариев, не обещание фиксированной высоты для любых городов и пожеланий. Длинный раскрытый список прокручивается внутри блока.

## Проверки и воспроизведение

Приложение запускалось локально в `ODIN_MODE=rules`, без вызова платной языковой модели. Для карты использовался существующий каталог через подключение SQLite только для чтения. Зависимости использовались из уже установленного Python-окружения и дополнительных библиотек; новые окружения и копии каталога не создавались.

Команды в обычном установленном окружении проекта:

```text
ODIN_MODE=rules python -m apps.web
python -m pytest tests/test_chat_navigation.py tests/test_refinement_20261029.py tests/test_unified_experience.py tests/test_party_dialogues_20261029.py tests/test_temperature_20261028.py -q
npx --yes --package @playwright/cli playwright-cli -s=trip-sentence open http://127.0.0.1:8080/
npx --yes --package @playwright/cli playwright-cli -s=trip-sentence --raw run-code --filename tools/verify_trip_sentence.js
npx --yes --package @playwright/cli playwright-cli -s=trip-sentence --raw run-code --filename tools/verify_trip_sentence_edges.js
```

В Windows `ODIN_MODE` нужно установить штатным способом оболочки перед запуском. Если локальный каталог карты ещё не собран, связанные проверки требуют подготовки данных согласно README проекта. Браузерный сценарий использует текущий адрес уже открытой страницы. Сценарии содержат синтетические запросы; реальные пользовательские профили не нужны.

Итоговые результаты: **68 Python-проверок PASS** (54 проверки навигации, интерфейсных сценариев и состава поездки; 14 температурных проверок), **35 браузерных критериев PASS** (28 основных + 7 границ). `node --check` для изменённых JS и `git diff --check` — PASS. Сохранены очищенные результаты браузерных сценариев в `docs/evidence/trip-sentence-20261029/`.

Проверены самостоятельные изменения всех шести основных полей, погоды, сохранение остальных условий, календарь, отмена, клавиатура, Escape и возврат фокуса, отсутствие повторного запроса при неизменённом вводе, сохранение правки при отказе сети и повторная отправка, показ валюты, раскрытие дополнительных условий, переход года, неизвестное название с HTML-символами, сохранение возраста детей, телефон, узкий экран и тёмная тема.

## Ограничения

Проверки подтверждают локальный интерфейс и работу с текущим сервером правил. Реальная облачная языковая модель, реальные поставщики, бронирование и оплата не проверялись. Погода в блоке означает сохранённое пожелание пользователя; проверка климатических ограничений по-прежнему использует исторические данные, а не обещает прогноз на август 2027 года. Свободный текст в редакторе проходит существующий разбор: неподдержанное пожелание может потребовать уточнения в чате. Неизвестные географические названия отображаются без выдуманного склонения.

Подготовлена отдельная локальная версия с просмотром на `http://127.0.0.1:18193/`; основной запущенный сайт и незавершённые файлы соседнего чата не заменены. Слияние, публикация и развёртывание этой версии не выполнялись.
