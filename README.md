# AI-агент подбора отелей

Прототип для трека «О!дин запрос» «О! Хакатона» (Ostrovok.tech, 23–30 октября 2026): пользователь пишет, куда и как хочет поехать, а агент подбирает отели и объясняет выбор.

## Быстрый старт

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
cp .env.example .env          # LLM_API_KEY: Cloud.ru или любой OpenAI-совместимый провайдер
.venv/bin/python -m pytest -q # тесты не требуют сети
.venv/bin/python -m apps.cli --debug
```

Пример запроса: «Питер на выходные до 8 тысяч за ночь, с завтраком, поближе к центру».

## Как это работает

LLM извлекает из запроса параметры поездки в Pydantic-схему. Код сливает их с состоянием диалога, ищет по каталогу и ранжирует варианты. Если точных совпадений нет, фильтры ослабляются по лестнице, и агент говорит, что именно ослабил. Причины выбора и цены берутся из каталога, поэтому агент не может их выдумать. Каталог пока вымышленный: 40 отелей в 5 городах.
