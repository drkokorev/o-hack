# AI-агент подбора отелей

Прототип для трека «О!дин запрос» «О! Хакатона» (Ostrovok.tech, 23–30 октября 2026): пользователь пишет, куда и как хочет поехать, а агент подбирает отели и объясняет выбор.

## Быстрый старт

```bash
make install                  # .venv и зависимости
make test                     # тесты без сети
make web                      # веб-демо на http://localhost:8000 (другой порт: make web PORT=8010)
```

Без ключа LLM агент работает на правилах. Чтобы подключить модель, скопируйте `.env.example` в `.env`, впишите `LLM_API_KEY` (Cloud.ru или любой OpenAI-совместимый провайдер) и проверьте доступ командой `make llm-check`.

Пример запроса: «Питер на выходные до 8 тысяч за ночь, с завтраком, поближе к центру». Дальше можно уточнять: «а подешевле?», «бюджет не важен», «давай заново, теперь Сочи».

| Команда | Что делает |
| :--- | :--- |
| `make web` | Веб-демо: чат, карточки отелей с причинами выбора, панель понятых параметров |
| `make cli` | Консольный чат с отладкой состояния |
| `make eval` | Метрики понимания на двух наборах → `eval/report.md`, `eval/report_holdout.md` |
| `make inspect DATA=data/` | Обзор выданных данных: колонки, пропуски, что распознал загрузчик каталога |
| `HOTELS_PATH=data/hotels.csv make web` | Демо на каталоге из файла (CSV, JSON, JSONL, Parquet, Excel) |

## Как это работает

LLM извлекает из запроса параметры поездки в Pydantic-схему. Правила дополняют то, что модель пропустила, и подменяют её при сбое. Код сливает параметры с состоянием диалога, ищет по каталогу и ранжирует варианты. Если точных совпадений нет, фильтры ослабляются по лестнице, и агент говорит, что именно ослабил. Причины выбора и цены берутся из каталога, поэтому агент не может их выдумать. Встроенный каталог вымышленный: 40 отелей в 5 городах.

## Качество понимания

Правила без LLM (`make eval`, 22 октября): 35 из 36 диалогов настроечного набора и 7 из 20 отложенного (полнота полей 100% и 69%, точность 99% и 91%). Отложенный набор не используется для подгонки правил: он показывает, что на незнакомых формулировках нужна LLM. Режимы `llm` и `hybrid` считаются после подключения ключа.
