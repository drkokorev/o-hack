# О!дин запрос — AI-агент поездки (трек «О!дин запрос»)

Пользователь описывает поездку обычными словами, а агент уточняет недостающие сведения, предлагает направления и собирает демонстрационные варианты. Есть полный сайт и встраиваемый чат. Цены, расписания, наличие и оформление — демонстрация: деньги не списываются, реальные брони и билеты не создаются.

- Видео-скринкаст: _добавим к сдаче_
- Развёрнутый сервис: _опционально_

## Быстрый старт

```bash
git clone git@github.com:ostrovok-hackathon-2026/iskusstvennyi-praim.git
cd iskusstvennyi-praim
cp .env.example .env   # необязательно: без ключа LLM агент работает на правилах
docker compose up --build
# открыть http://localhost:8080
```

Попробуйте: «В Сочи из Москвы с 5 по 12 декабря вдвоём» → на вопрос о составе ответьте «2 взрослых» → «беру 1 вариант» → «да, оформляй» → «оплата СБП» → «да, подтверждаю». Или опишите отдых без точных дат: агент уточнит их или предложит идеи без расчёта стоимости.

## Языковая модель и надёжность

Модель необязательна: без неё работает разбор по правилам, но он понимает меньше формулировок. Можно подключить облачный OpenAI-совместимый API или GigaChat (`LLM_PROVIDER=gigachat` и `GIGACHAT_AUTH_KEY`), либо отдельно запущенный локальный совместимый сервер (`LLM_PROVIDER=local`, `LLM_BASE_URL`, `LLM_MODEL`). Локальному серверу облачный ключ не нужен; модель и сервер не входят в контейнер. При передаче решения учитывайте условия конкретного поставщика: личный бесплатный ключ GigaChat предназначен для личных тестов и не передаётся третьим лицам. Проверка подключения: `make llm-check`.

Пример подключения Cloud.ru при наличии разрешённого доступа:

```bash
cp .env.example .env
# в .env: LLM_API_KEY=<ключ сервисного аккаунта Cloud.ru>
#         LLM_MODEL=Qwen/Qwen3-235B-A22B-Instruct-2507  (или openai/gpt-oss-120b)
make llm-check      # связь, JSON-режим, задержка и понимание 8 фраз: LLM против правил
make simulate       # LLM играет 8 путешественников
```

Модель только понимает реплику. Её ответ сверяется с текстом и с правилами (`domains/trips/arbiter.py`):

- оформление и отмена — только по явному согласию, которое видят правила; «давай подумаем», «да нет», вопрос — не согласие; отмена брони в два шага;
- поле без опоры в тексте отбрасывается (модель выдумала «с собакой» или повторила «на два дня позже» из прошлой реплики);
- в датах, числах и действиях главнее правила;
- после трёх сбоев подряд модель 30 секунд не вызывается, агент идёт по правилам; отказ провайдера от `response_format` и ответ «в форме схемы» обрабатываются.

## Качество

`make test` запускает автономные тесты диалога, дат, состояния, приватности, каталога, карты данных и демонстрационного оформления. Контракт поиска Островка проверяется на имитации ответов и не создаёт сетевых бронирований. `make eval` и `make simulate` содержат дополнительные сценарии; для проверки с языковой моделью нужен настроенный провайдер. Результаты отдельных экспериментов не гарантируют качество на произвольных запросах.

## Зависимости и переменные окружения

Рекомендованные ресурсы: 1 CPU, 512 МБ RAM. Внешних сервисов (БД, кэш) нет: состояние диалогов в памяти процесса, данные лежат в образе.

| Переменная | По умолчанию | Назначение |
| :--- | :--- | :--- |
| `APP_PORT` | `8080` | Порт приложения |
| `APP_BIND_HOST` | `127.0.0.1` | Адрес на компьютере; `0.0.0.0` открывает доступ извне |
| `SESSION_TTL_SECONDS` | `3600` | Срок хранения неактивной сессии в памяти |

## Данные

У команды пока нет доступа к партнёрскому API Островка. Мы используем открытые датасеты и явно помечаем модельные данные:

- **Отели — реальные.** 65 107 настоящих объектов размещения (отели, резорты, гостевые дома, апартаменты, хостелы) из открытого датасета [Overture Maps Places](https://overturemaps.org) (CDLA Permissive 2.0): название, координаты, адрес, сайт. Основные 34 направления — все объекты без лимита (Бали — 13 871, Шри-Ланка — 7 215, Стамбул — 6 182, Пхукет — 4 694, Анталья — 3 568, Москва — 2 086, Большой Сочи — 946, без Абхазии: объекты другой страны отсекаются); ещё 35 направлений по миру (Европа, Азия, Ближний Восток, Африка, Америка) — до 300 лучших объектов на каждое. Расстояние до моря считается по реальным пляжам из того же датасета, до аэропорта — по координатам OurAirports. Файл `domains/trips/data/hotels.json` лежит в репозитории и пересобирается командой `python -m tools.build_hotels` (DuckDB читает GeoParquet из публичного S3 по границам района, без ключей).
- **Цены, рейтинги, питание и условия отмены отелей — модельные.** Их нет в открытых данных; в карточке так и написано: «Настоящий объект · цены и рейтинг — модель».
- **Климат — исторические данные.** Средние по месяцам за 2022–2025 годы из [Open-Meteo](https://open-meteo.com) (CC BY 4.0): температура днём и ночью, дождливые дни, температура моря. Это не прогноз погоды на конкретную поездку. Файл `domains/trips/data/climate.json`, пересборка — `python -m tools.build_climate`.
- **Фото направлений — реальные**, из Wikimedia Commons со свободными лицензиями: главное фото и галерея из лучших снимков (категории Featured pictures и Quality images). Автор и лицензия подписаны на каждом снимке (`tools/build_images.py`, `apps/static/img/credits.json`). Фото отелей — иллюстрации по типу отеля, так и подписаны.
- **Карта — реальная.** Контуры суши Natural Earth 110m (public domain), направления можно выбрать на карте.
- **Встраиваемый чат.** На странице сервиса разместите `<script src="http://localhost:8080/static/embed.js" defer></script>`, заменив адрес на адрес развёрнутого приложения. Откроется компактный чат с тем же сервером и логикой, что у полного интерфейса. Виджет не считывает содержимое страницы, на которую его вставили. Для публичного развёртывания используйте HTTPS и проверьте политику безопасности сайта.
- **География и интеграция.** Поиск географических названий использует 161 662 записи GeoNames; это не каталог предложений. Реальные доступность, тарифы и бронирование не подключены. [Схема возможной интеграции с Островком](docs/03_ostrovok_integration.md) отдельно показывает готовые и будущие шаги; read-only адаптер поиска проверен только на имитации ответов API.
- **Демо-предложения.** Каталог сценариев охватывает 69 направлений и 7 городов отправления. Реальное наличие рейсов, их маршруты и визовые требования не проверяются; эти сведения нужно получать у поставщиков и проверять отдельно.
- **Рейсы, поезда, трансферы и их цены — модельные (синтетика).** Генерируются детерминированно: время в пути считается по реальному расстоянию, цены зависят от сезона, перевозчики вымышленные («Авиа Альфа»). Оплата имитируется.

Для перехода на настоящий источник потребуется связать поиск с актуальными тарифами и проверкой брони; готовый read-only адаптер пока не является заменой демо-планировщика. Дальнейшие шаги и границы интеграции описаны в [схеме](docs/03_ostrovok_integration.md).

Сидирование не нужно: всё создаётся при старте.

## Маршруты

- `/` — веб-интерфейс с картой, чатом, вариантами и демонстрационным оформлением
- `/static/widget-demo.html` — пример встраиваемого чата на странице другого сайта
- `/health` — `{"status": "ok"}`
- `POST /api/chat` — `{"text": "...", "session_id": "..."}` → ответ агента, этап, понятые параметры и данные для карточек
- `GET /api/info`, `POST /api/reset`, `/api/docs` — описание API

Тестовые учётные данные не нужны.

## Как устроено

Управляемый агент: LLM извлекает из реплики пожелания и действия в Pydantic-схему, а решения принимает код — какой вопрос задать, какие направления предложить и когда показать демонстрационное оформление. Правила уменьшают число неподтверждённых предположений, но не гарантируют отсутствие ошибок. Отели и цены в демонстрационных вариантах не являются проверенными предложениями.

```
реплика → защита от инъекций → понимание (LLM, правила дополняют и страхуют)
        → слияние с состоянием поездки → решение этапа:
          нет направления  → идеи без выдуманных дат и цен, либо подбор при достаточных данных
          нет параметров   → уточняющий вопрос; если человек не знает, не повторять его бесконечно
          всё есть         → 3 варианта: оптимальный / экономный / комфорт + проверка состыковок
          выбор            → корзина → выбор демо-оплаты → отдельное подтверждение → условный заказ
        → изменения («на два дня позже», «дешевле», «с собакой») пересобирают план и показывают, что изменилось
```

| Путь | Назначение |
| :--- | :--- |
| `domains/trips/geo.py`, `domains/trips/data/geo.json` | Проверка и загрузка справочника направлений, городов вылета и пересадок; расчёт расстояний |
| `domains/trips/climate.py` | Климат по месяцам (Open-Meteo) |

| `domains/trips/dialogue.py`, `tent.py` | Уточнения и идеи без цены; отдельный сценарий со своей палаткой |
| `domains/trips/world_places.py`, `providers/ostrovok.py` | Географический справочник и изолированная заготовка поиска по API Островка |

## Разработка

```bash
make install   # .venv и зависимости
make test      # тесты без сети
make run       # приложение на http://localhost:8080 без Docker
make up        # docker compose up --build
make eval      # набор диалоговых сценариев без сети, eval/guided_report.json
make simulate  # LLM играет путешественников (нужен ключ)
```
