# O_HACK: универсальное агентное ядро

Одно ядро на два хакатона осени 2026:
- **«О! Хакатон»** (Ostrovok.tech, трек «О!дин запрос», 23–29 окт): AI-агент подбора отелей по свободному запросу.
- **«Точка сборки»** (producthack.ru, 13–31 окт): голосовой ассистент записи в клинику (кейс DBI).

## Быстрый старт

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
cp .env.example .env          # необязательно: LLM_API_KEY (Cloud.ru или любой OpenAI-совместимый провайдер)
.venv/bin/python -m pytest -q # тесты не требуют сети
.venv/bin/uvicorn apps.web.server:app --port 8000   # веб-макет DBI → http://localhost:8000
.venv/bin/python -m apps.cli clinic --debug          # то же в консоли
```

Без ключа LLM макет работает на разборе по правилам. Голос распознаётся браузером: нужен Chrome или Edge и разрешение на микрофон.
Docker: `docker build -t clinic-assistant . && docker run -p 8000:8000 --env-file .env clinic-assistant`.

## Что проверить в макете

| Сценарий | Что сказать |
| :--- | :--- |
| Запись | «Запишите к терапевту на среду после обеда» → «второй» → «Петров Иван» |
| По жалобе | «Болит зуб, можно в пятницу?» |
| Расписание | «Когда принимает Белова?» → «да» |
| Статус | «Хочу узнать, на когда я записан» → «Иванов Иван» |
| Перенос | «Мне нужно перенести запись» → «Смирнова Анна» → «первый» |
| Отмена | «Отмените мою запись» → «Петров Сергей» → «да» |

Записи у тестовых пациентов уже есть: Иванов Иван, Смирнова Анна, Петров Сергей. Кнопка «Сбросить демо» возвращает расписание в исходное состояние.

## Как это работает

На каждой реплике LLM извлекает изменения параметров в Pydantic-схему. Python сливает их с состоянием диалога и решает, что делать дальше: задать уточняющий вопрос, выполнить поиск или запись. Если результатов нет, фильтры ослабляются, и бот объясняет, что именно ослабил. Ответы собираются по шаблону, поэтому факты выдумать невозможно. Перефразирование через LLM можно включить флагом `LLM_NLG=1`.
