# Сторонние библиотеки и сервисы

Перечень по п. 5.5.4 Положения «Точки сборки». Версии взяты из рабочего окружения 10 октября 2026.

## Библиотеки Python

| Библиотека | Версия | Лицензия | Зачем |
| :--- | :--- | :--- | :--- |
| pydantic | 2.13.5 | MIT | Схемы данных и валидация ответов LLM |
| openai | 3.24.0 | Apache-2.0 | Клиент OpenAI-совместимого API (Cloud.ru Foundation Models и др.) |
| python-dotenv | 1.2.4 | BSD-3-Clause | Настройки из `.env` |
| fastapi | 0.142.4 | MIT | HTTP API веб-макета |
| uvicorn | 0.54.0 | BSD-3-Clause | Сервер приложения |
| httpx | 0.28.1 | BSD-3-Clause | Тестовый клиент API (только для разработки) |
| pytest | 9.1.1 | MIT | Тесты (только для разработки) |

## Внешние сервисы

| Сервис | Где используется | Условия |
| :--- | :--- | :--- |
| LLM через OpenAI-совместимый API (по умолчанию Cloud.ru Evolution Foundation Models) | `core/llm.py`, по ключу из `.env` | По условиям провайдера; без ключа работает разбор по правилам |
| Web Speech API браузера (распознавание и синтез речи) | `apps/web/static/index.html` | Встроен в браузер; обработку выполняет поставщик браузера. Временное решение для прототипа |

Данные врачей, расписания, пациентов и отелей в репозитории вымышленные.
