# Исходники монтажа

Запись приложения: 53a2aa7. Windows, Python 3.14. Требуются `pillow`, `numpy`, `imageio-ffmpeg`; для новой записи — `playwright` и Chrome. Шрифты титров: системные Segoe UI, не распространяются в репозитории.

Из этой папки выполните `python build_promo.py all`. Результат появится в `../outputs/`. `recordings/main-take.webm` и `widget-take.webm` — успешные исходные записи, `capture.json` содержит временные границы и обезличенные результаты, `raw-path.txt` — относительный путь. Файлы `render/` воспроизводимы.

Для новой записи поднимите приложение по инструкции README на 8080 и выполните `python capture_demo.py`, затем `python capture_widget.py`. Модель, ключ и каталог конфигурируются обычным способом приложения и не входят в материалы ролика. `voice-input.wav` — синтетический аудиопример для виртуального микрофона; настоящую GigaAM он не заменяет. При новой записи ответы и тайминги могут отличаться.

Фильм и публичная страница: https://rigby453.github.io/odin-zapros-demo-2026/
